# 📰 Leis Trabalhistas: Uruguai e Argentina

Uma análise sobre direitos trabalhistas, condições de trabalho e cenário econômico em dois países da América Latina: **Uruguai 🇺🇾 e Argentina 🇦🇷**.

## 📌 Sobre o projeto

Este projeto foi desenvolvido como uma atividade acadêmica com o objetivo de apresentar e comparar aspectos das **leis trabalhistas** do Uruguai e da Argentina.

Além da análise dos direitos trabalhistas, o projeto também apresenta um panorama econômico dos dois países, abordando indicadores como PIB, crescimento econômico, desemprego, inflação, renda e principais atividades econômicas.

A página foi desenvolvida como um complemento ao trabalho proposto, buscando apresentar as informações de forma organizada e com uma identidade visual inspirada em uma matéria jornalística.
